# HR Analytics Dashboard

## 📌 Project Overview
This HR Analytics Dashboard was developed using Power BI to analyze employee attrition, workforce trends, job satisfaction, and overall employee performance. The dashboard helps HR teams make data-driven decisions and identify key factors affecting employee retention.

## 🎯 Objectives
- Analyze employee attrition trends
- Monitor workforce demographics
- Track job satisfaction levels
- Identify departments with high attrition
- Support HR decision-making with data insights

## 🛠 Tools & Technologies
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Dashboard Design

## 📊 Key Metrics
- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Job Satisfaction Score
- Department-wise Employee Distribution

## 📈 Dashboard Insights
- Employee attrition analysis
- Department-wise performance tracking
- Gender distribution analysis
- Job role analysis
- Workforce trend visualization
